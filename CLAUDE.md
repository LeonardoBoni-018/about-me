# about-me — portfólio de Leonardo Rodrigues Boni

Portfólio pessoal (engenheiro backend, Java/Spring e Go) em Next.js 16 + React 19 + Tailwind v4,
bilíngue (PT-BR/EN), conceito "ciclo de vida de uma requisição" (blueprint). Conteúdo pessoal em `src/content/`,
textos de interface em `src/i18n/messages/`.

## Skills do projeto (use antes de agir)

| Skill             | Quando                                                        |
| ----------------- | ------------------------------------------------------------- |
| `frontend-design` | qualquer mudança de UI, estilo, animação ou texto visível     |
| `testing`         | escrever/rodar testes, verificação visual por screenshots     |
| `git-workflow`    | commits, branches, push (sempre confirmar push com o usuário) |
| `documentation`   | README, `docs/`, ADRs, CHANGELOG                              |

## Comandos

- `npm run dev` · `npm run build` · `npm start`
- Gate: `npm run lint && npm run typecheck && npm test` (+ `npm run test:e2e` em mudanças de UI)
- `npm run format` antes de commitar

## Onde ler mais

- `docs/arquitetura.md` — rotas, i18n, tema, formulário, fluxo de dados
- `docs/conteudo.md` — como editar o conteúdo do site
- `docs/adr/` — decisões e seus porquês
